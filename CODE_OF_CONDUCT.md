# Code of conduct

Sleuth is a small open source project and it should stay friendly.

## Expected behaviour

- Be respectful and assume good faith.
- Critique code, not people.
- Keep discussions focused on the work.

## Unacceptable behaviour

Harassment, insults, personal attacks, publishing private information and any other conduct that
would make this project unwelcoming.

## Enforcement

Report problems to the maintainer. Issues may be edited or removed, and contributors whose
behaviour is harmful may be banned from the project.

This is adapted from the [Contributor Covenant](https://www.contributor-covenant.org), version 2.1.
