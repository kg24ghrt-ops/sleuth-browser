Android WebView browser

Sleuth

A browser that works like any other browser — tabs, history, bookmarks, downloads, incognito — and can take real screenshots, mark them up like evidence, and file them into local case files that never leave the device.

What it does

Browses properly

Omnibox, tabs, find on page, downloads, bookmarks, history, share, desktop mode, deep links and per-site blocking.

Captures evidence

PixelCopy screenshots, stitched full page captures, and an evidence lab with pen, marker, box, circle, arrow, labels and pixel redaction.

Keeps the record

Case files with codes, notes, a stakeout switch, a timeline and export to a self contained HTML report or JSON.

Refuses to be locked down

Copy blocks, selection blocks and hidden print stylesheets are overruled before the page loads, and every attempt is filed as evidence.

Stays quiet

No assistant, no chat, no speaking. You may say where to go and it is handled like a typed query, never like a conversation.

Detective's rules

  1. It never talks to you. It listens only when you ask it to, and it only ever hears a destination or a search.
  2. It never asks questions it can answer itself.
  3. Everything you type or say is a destination or a search.
  4. Feedback is silent and reversible.
  5. Nothing leaves the device unless you export it.
